# Pi Package for MCP Gateway

Official Pi package providing the `mcp-gateway` extension (`pi.registerMcpServer` + `tool_call` workspace provenance signing + `/mcp-gateway` status command) and skill.

## Install

```sh
pi install git:github.com/DengNaichen/mcp-gateway
```

Or use the **MCP Gateway** desktop app (`连接客户端` → `安装插件`) / `gatewayctl plugin install -client pi` to install a runtime-configured package pointing to your active Stable/Dev endpoint.
