## 升级说明

Stable 的 Bundle ID、用户数据库目录、默认 8788 端口与更新公钥保持不变，不迁移桌面用户数据。Dev 使用 8789 和独立数据库。旧版独立后端与新版桌面端的身份不匹配时会明确提示端口冲突，升级后需重启对应后端。

命令行开发入口的默认数据目录改为 `data/dev`；已有 CLI 注册表可通过显式 `-data <原目录>` 使用。模型、身份验证等 `GATEWAY_*` 环境变量仍共享；仅数据目录和公开地址为 Dev 提供 `GATEWAY_DEV_DATA_DIR` / `GATEWAY_DEV_PUBLIC_URL`，开发时应按需明确设置凭据环境。

客户端配置旁的 `.mcp-gateway.lock` 是两版协调写入的持久锁文件，撤回时不会删除；不含凭据。配置状态代表文件状态，客户端重载后才建立连接。
