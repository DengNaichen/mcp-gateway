# Client brand marks

Bundled locally for identifying supported clients; no runtime network requests.

- Codex: OpenAI mark from the masthead of https://developers.openai.com/codex (inline SVG).
- Claude Code: Claude asterisk extracted without geometry changes from the official wordmark at https://claude.com (symbol path only).
- Cursor: https://cursor.com/marketing-static/favicon-light.svg
- OpenCode: `services/site/src/asset/brand/opencode-logo-dark-square.svg` in https://github.com/anomalyco/opencode, also listed at https://opencode.ai/brand.
- Pi: https://pi.dev/logo-auto.svg
- Antigravity: official Google Antigravity arch silhouette from https://antigravity.google/ (https://antigravity.google/favicon.svg), rendered with pure SVG radial gradients for cross-renderer compatibility without filter blurs.
