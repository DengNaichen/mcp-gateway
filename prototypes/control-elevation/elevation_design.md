# 控件阴影对比

交互原型：[elevation.html](elevation.html)。沿用 [控制面设计规范](../control-plane/control_plane_design.md) 的配色、字体、圆角与低噪声原则。

已确认采用轻微浮起方向。并排展示调整前样式与轻微浮起样式，覆盖导航选中项、操作按钮和内容卡片；两边导航同步切换，支持浅深色外观、键盘聚焦和按钮按压反馈。

## 浅色规范

| 元素 | 边框 | 外阴影 |
| --- | --- | --- |
| 当前导航、卡片 | `#e5e9f0` | `0 1px 2px rgba(15,23,42,.035)` |
| 浮起导航、按钮 | `rgba(15,23,42,.065)` | `0 2px 6px rgba(15,23,42,.07)` |
| 浮起卡片 | `rgba(15,23,42,.065)` | `0 3px 10px rgba(15,23,42,.04)` |
| 下拉浮层 | 沿用控件边框 | `0 6px 18px rgba(15,23,42,.12)` |
| 弹窗、悬浮抽屉 | 沿用控件边框 | `0 12px 36px rgba(10,37,64,.25)` |

阴影沿正 Y 轴向下偏移，留在表面外侧。优先减轻描边，再用柔和投影表达高度；按钮按住时撤去投影，不添加内阴影。内容卡片比交互控件更淡，内容列表继续使用细分割线，不为每行添加阴影。

## 深色规范

采用中性炭黑（Zinc）阶梯表面区分层次（侧栏 `#1a1a1e`、主画布 `#1a1a1e`、浮起卡片与选中导航 `#232327`、内嵌输入框 `#1c1c20`、控件 `#28282d`）。为保留与浅色一致的克制浮起质感，深色模式下在原生端使用 `0.5dp` 顶部受光渐变边框（`BorderLinearGradient`：顶边微亮 `rgba(255,255,255,0.055~0.06)` → 上侧 `0.015` → 36% 以下及底边完全透明），配合单层轻柔黑影（控件 `0.22`、卡片 `0.16`、下拉 `0.36`、弹窗 `0.50`，偏移和模糊范围与浅色一致），避免底边亮框线与双层过重投影；按住时撤去投影与渐变边框。

## 评审边界

当前列复现原生导航与卡片的声明参数；按钮是同一组表面参数的对比样本。CSS 与 MyGo 的模糊实现可能存在差异，原型用于确认方向；实现到原生端后仍需真实截图验收。
