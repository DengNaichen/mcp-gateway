# 桌面凭据持久化

沿用 [控制面规范](../control-plane/control_plane_design.md)，不增加一级导航。

- 「访问与路由」保留现有密码框与清除操作。保存模型档案时保存密钥；提示系统钥匙串自动恢复，内存模式明确标记重启需重新提供。
- 「上游服务 → 连接与认证配置」保留环境变量引用，在连接配置下增加「服务凭据」区域。
- 每个被引用变量一行：变量名、掩码输入、当前来源/状态与清除按钮。空白输入保留已有值，显式清除只删除已保存值，不改变外部环境变量。
- 输入框从不回显已存密钥；状态只返回 configured / saved。显示已保存、由运行环境提供、未配置；非持久化实例改为仅本次运行。
- 保存失败直接显示错误，保留新输入供重试；成功后清空输入并刷新状态。配置变更后刷新凭据列表。
- OAuth 浏览器回调页仅显示「已收到授权回调」，引导返回应用查看连接结果；收到授权码不代表令牌交换、凭据保存或 MCP 连接已成功。授权失败立即在应用返回具体错误，同一次连接的协议回退不重复打开浏览器。
- 环境变量优先于服务保存值。历史环境变量引用保持原样；用户在服务凭据栏填入相应值后完成绑定，不自动把进程环境全部写入钥匙串。
- 模型启动环境变量只覆盖启动时激活的档案，不持久化；界面显式更新/清除后以本次操作为准。
- 设计预览：[credentials.html](credentials.html)。
